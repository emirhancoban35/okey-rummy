# Coffeehouse art

The backdrop and honey oak rack were generated with the built-in imagegen tool. The rack edit preserves the original two-shelf silhouette. UI panels, grids, labels and controls are editable objects in GameControls.prefab, rather than part of the texture.

## Backdrop prompt

Game environment texture, wide 16:9 flat overhead view of an EMPTY inviting Turkish coffeehouse okey table. Main surface is softly lit light desaturated sage green felt, very subtle fine fabric texture, perfectly uniform spacious empty center occupying 97 percent of image. Very thin honey oak rounded edge at outermost border only, no ornate metalwork. Contemporary cozy tabletop game art, warm daylight, gentle matte finish, clean and understated. NOT dark or dramatic. No tiles, no racks, no cups, no grids, no boards, no panels, no UI, no writing, no logo, no watermark. This is a backdrop to be overlaid with editable game UI.

## Rack prompt

Edit this okey tile rack asset: preserve its exact wide silhouette, two empty horizontal shelves, shelf positions, perspective and transparent outer background. Change only the wood finish from dark brown walnut to warm light honey oak with restrained subtle wood grain, soft daytime highlights and gently rounded edges. Inviting contemporary coffeehouse tabletop game art, readable and uncluttered. No stones, text, decorations, logos or background. Actual transparent background outside the rack. Maintain 4:1 wide aspect ratio and empty shelf surfaces.
