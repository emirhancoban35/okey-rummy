# Coffeehouse art

The backdrop and honey oak rack were generated with the built-in imagegen tool. The active rack uses `FlatOakRack.png`, a straight front-facing two-row rack. `WarmOakRack.png` is the older perspective variant. UI panels, grids, labels and controls are editable objects in GameControls.prefab, rather than part of the texture.

Very thin honey oak rounded edge at outermost border only, no ornate metalwork. Contemporary cozy tabletop game art, warm daylight, gentle matte finish, clean and understated. NOT dark or dramatic. No tiles, no racks, no cups, no grids, no boards, no panels, no UI, no writing, no logo, no watermark. This is a backdrop to be overlaid with editable game UI.
