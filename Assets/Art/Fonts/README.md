# Table typography

The table interface uses Nunito Bold. The font is distributed under the SIL Open Font License in `OFL.txt`.

Source: [Google Fonts Nunito](https://github.com/google/fonts/tree/main/ofl/nunito), downloaded on October 11, 2026. The included TTF file is a static instance of the upstream variable font at weight 700.

The TextMesh Pro SDF asset contains Latin characters, English UI punctuation and Turkish letters. It uses a static 1024 × 1024 atlas generated at 90 pt with 9 px padding. Typography and layout are assigned in `GameControls.prefab` and `Stone.prefab`; rack geometry is configured in `Istaka.prefab`.
